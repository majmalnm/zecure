مصمَّم ليكون آمنًا تشفيريًا

تستخدم معظم مولّدات كلمات المرور Math.random() — وهي دالة شبه عشوائية يمكن التنبؤ بنتائجها ولا تصلح للاستخدامات الأمنية. أما Zecure فيستخدم window.crypto.getRandomValues()، وهو مولّد CSPRNG نفسه الذي يعتمد عليه نظام تشغيلك.

تُنشأ كل كلمة مرور ومفتاح ورمز محليًا داخل متصفحك. لا يوجد خادم. افصل اتصالك بالإنترنت وأعد تحميل الصفحة — وسيعمل بالطريقة نفسها تمامًا.

  • CSPRNG — مولّد أرقام شبه عشوائية آمن تشفيريًا
  • أسلوب أخذ العينات بالرفض (rejection sampling) يزيل انحياز باقي القسمة (modulo bias) عند اختيار الأحرف
  • لا طلبات شبكة، ولا ملفات تعريف ارتباط (cookies)، ولا تحليلات، ولا تسجيل على الخادم
  • افحص الشيفرة المصدرية بنفسك — افتح DevTools ← Sources
  • يعمل دون اتصال بالإنترنت بعد التحميل الأول
entropy.js
// CSPRNG المتصفح — المصدر نفسه الذي يستخدمه نظام التشغيل
function secureBytes(n) {
  const arr = new Uint8Array(n);
  crypto.getRandomValues(arr);
  return arr; // لا يغادر متصفحك أبدًا ✓
}
