أي خوارزمية تجزئة تستخدم؟

لا تخدم كل دوال التجزئة الغرض نفسه. إليك متى تستخدم كلًّا منها:

لا تستخدم هذه الدوال أبدًا لتجزئة كلمات المرور. صُمّمت SHA-256 وSHA-512 لتكون سريعة، فيستطيع المهاجم اختبار مليارات التخمينات في الثانية. استخدم بدلًا منها bcrypt أو Argon2id أو scrypt لتخزين كلمات المرور.

استخدامات شائعة لدوال التجزئة التشفيرية

  • التحقق من سلامة الملفات: نزّل الملف، واحسب قيمة SHA-256 له، وقارنها بمجموع التحقق الذي نشره الناشر. إذا تطابقتا، فالملف لم يُعبث به.
  • تخزين مفاتيح API: خزّن قيمة SHA-256 لمفتاح API في قاعدة بياناتك بدل المفتاح نفسه. ومع كل طلب، احسب قيمة التجزئة للمفتاح الوارد وقارن. حتى تسريب قاعدة البيانات كاملة لن يكشف مفاتيح صالحة للاستخدام.
  • إزالة البيانات المكررة: احسب قيمة التجزئة لمحتوى الملفات لاكتشاف المكرر منها دون مقارنتها بايتًا ببايت.
  • التوقيع بـ HMAC: استخدم SHA-256 داخل HMAC (رمز مصادقة الرسائل المبني على التجزئة) لإثبات أن الرسالة لم تُعدَّل وأنها جاءت من مصدر موثوق.
  • التخزين المعنون بالمحتوى: خزّن البيانات وابحث عنها بقيمة التجزئة الخاصة بها (مثلًا، يستخدم Git خوارزمية SHA-1 / SHA-256 لمعرّفات commit وblob).

الأسئلة الشائعة

دالة التجزئة تأخذ أي مدخل وتنتج مخرجًا بطول ثابت يُسمى الملخّص (digest) أو قيمة التجزئة (hash). المدخل نفسه ينتج دائمًا قيمة التجزئة نفسها، لكن أصغر تغيير في المدخل ينتج قيمة مختلفة تمامًا. والأهم أنها دالة أحادية الاتجاه: لا يمكنك عكس قيمة التجزئة لاسترجاع المدخل الأصلي.

MD5 عرضة لهجمات التصادم، أي أن مدخلين مختلفين قد ينتجان قيمة MD5 نفسها. في 2004 أثبت باحثون إمكانية إحداث تصادمات عمليًا. وفي 2008 زُوّرت شهادة CA مزيفة باستخدام تصادمات MD5. لأي غرض أمني (التواقيع، الشهادات، تخزين كلمات المرور) يجب عدم استخدام MD5.

لا. SHA-256 دالة تجزئة سريعة للأغراض العامة، ويستطيع المهاجم تجربة نحو 10 مليارات تخمين SHA-256 في الثانية على GPU حديث. تخزين كلمات المرور يتطلب خوارزمية بطيئة عمدًا مع معامل تكلفة: استخدم bcrypt (بتكلفة 12 أو أكثر) أو Argon2id (الذي توصي به OWASP) أو scrypt. صُمّمت هذه الخوارزميات لتبقى بطيئة حتى مع تطوّر العتاد.

لا. تجري كل عمليات التجزئة داخل متصفحك. تستخدم SHA-1 وSHA-256 وSHA-512 واجهة Web Crypto API المدمجة في المتصفح (crypto.subtle.digest()). أما MD5 فتُحسب بتطبيق JavaScript يعمل بالكامل داخل المتصفح. افتح DevTools → Network ولن ترى أي طلبات صادرة عند التجزئة.
