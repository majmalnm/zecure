شرح ترميز Base64: ما هو ومتى تستخدمه

أبريل 2026 قراءة 7 دقائق بقلم فريق Zecure

لا بد أنك رأيت سلاسل Base64 في كل مكان: في JWT، وترويسات HTTP، وروابط البيانات (data URI)، ومرفقات البريد الإلكتروني. لكن ما هو Base64 بالضبط، وكيف يعمل، ومتى ينبغي أن تستخدمه فعلًا؟ يجيب هذا الدليل عن الأسئلة الثلاثة.

ما هو Base64؟

Base64 مخطط ترميز يحوّل البيانات الثنائية إلى نص، إذ يحوّل أي بيانات ثنائية إلى سلسلة من أحرف ASCII القابلة للطباعة. ويأتي اسم "Base64" من كونه يستخدم أبجدية من 64 حرفًا بالضبط.

تتكون أبجدية Base64 القياسية من:

  • الأحرف الكبيرة: A–Z (26 حرفًا)
  • الأحرف الصغيرة: a–z (26 حرفًا)
  • الأرقام: 0–9 (10 أحرف)
  • رمزان خاصان: + و/ (حرفان)
  • حرف الحشو: = (ليس من الأحرف الـ 64، ويُستخدم لضبط المحاذاة)

كيف يعمل Base64؟

يعمل Base64 بتجميع كل 3 بايتات (24 بت) من بيانات الإدخال وترميزها في 4 أحرف Base64 (يمثّل كل منها 6 بتات). لنأخذ مثالًا بكلمة "Man":

ASCII
M (77) a (97) n (110)
ثنائي
01001101 01100001 01101110
مجموعات 6 بتات
010011 010110 000101 101110
Base64
T (19) W (22) F (5) u (46)

وهكذا تُرمَّز "Man" إلى TWFu. وهذه النسبة، 3 بايتات إلى 4 أحرف، هي سبب أن مخرجات Base64 أكبر دائمًا بنحو 33% من المدخلات الأصلية.

وماذا عن الحشو؟

لأن Base64 يعمل على مجموعات من 3 بايتات، يُضاف حشو إذا لم يكن طول المدخلات من مضاعفات 3 بايتات:

  • بايت واحد متبقٍّ ← حرفا Base64 + حشو ==
  • بايتان متبقيان ← 3 أحرف Base64 + حشو =
  • لا بايتات متبقية ← لا حاجة إلى حشو

Base64 القياسي مقابل Base64 الآمن للروابط (Base64url)

تتضمن أبجدية Base64 القياسية الرمزين + و/، ولهذين الرمزين معنى خاص في الروابط:

  • + في سلسلة الاستعلام داخل الرابط تعني حرف مسافة
  • / فاصل بين أجزاء المسار في الروابط

إذا وضعت سلسلة Base64 قياسية داخل رابط دون ترميزها بالنسبة المئوية (percent-encoding)، فإن هذين الرمزين يُفسدان الرابط. ولهذا أُنشئ Base64url (RFC 4648 §5):

الشكلالحرف 62الحرف 63الحشوالاستخدام
Base64 القياسي+/= مطلوبالبريد الإلكتروني (MIME)، والترميز العام
الآمن للروابط (Base64url)-_= اختياريJWT وOAuth ومعاملات الروابط
 
// JavaScript: Base64 القياسي والآمن للروابط
// الترميز إلى Base64 القياسي
const standard = btoa('Hello, World!');
// → "SGVsbG8sIFdvcmxkIQ=="

// الترميز إلى Base64 الآمن للروابط
const urlSafe = btoa('Hello, World!')
  .replace(/\+/g, '-')
  .replace(/\//g, '_')
  .replace(/=+$/, '');
// → "SGVsbG8sIFdvcmxkIQ"

متى يستخدم المطوّرون Base64؟

1. مصادقة HTTP Basic

عندما ترسل بيانات الدخول عبر HTTP Basic Auth، يرمّز المتصفح username:password بصيغة Base64 ويضعها في ترويسة Authorization:

Authorization: Basic dXNlcjpwYXNzd29yZA==
// "dXNlcjpwYXNzd29yZA==" is Base64("user:password")

ترميز Base64 في HTTP Basic Auth ليس تشفيرًا. يستطيع أي شخص يعترض الطلب فك ترميزه فورًا. استخدم HTTPS دائمًا مع Basic Auth.

2. رموز JSON Web Tokens (JWT)

يتكون JWT من ثلاثة أجزاء مرمّزة بـ Base64url تفصل بينها نقاط: header.payload.signature. الترويسة (header) والحمولة (payload) كائنات JSON مرمّزة بـ Base64url، مما يجعلها مقروءة لأي شخص؛ فرموز JWT ليست مشفّرة افتراضيًا، بل موقّعة فقط.

3. روابط البيانات (Data URI)

لتضمين ملفات ثنائية مثل الصور أو الخطوط مباشرة في CSS/HTML دون طلب HTTP منفصل، استخدم رابط بيانات (data URI):

<!-- تضمين صورة PNG صغيرة مباشرة في HTML -->
<img src="data:image/png;base64,iVBORw0KGgoAAAANS..." />

/* تضمين خط في CSS */
@font-face {
  src: url('data:font/woff2;base64,d09GRgAB...');
}

4. مرفقات البريد الإلكتروني (MIME)

صُممت بروتوكولات البريد الإلكتروني (SMTP) لنقل نصوص ASCII من 7 بتات فقط. لذلك تُرمَّز المرفقات الثنائية مثل ملفات PDF والصور بـ Base64 قبل تضمينها في نص الرسالة باستخدام MIME (Multipurpose Internet Mail Extensions).

5. تخزين البيانات الثنائية في JSON أو قواعد البيانات

لا يوجد في JSON نوع للبيانات الثنائية. فإذا احتجت إلى تخزين بيانات ثنائية أو إرسالها (مفاتيح تشفير، أو توقيعات، أو شهادات، أو صور) في حقل JSON، فرمّزها بـ Base64 أولًا.

ما ليس Base64

Base64 ليس تشفيرًا ولا وسيلة أمان. فهو قابل للعكس بالكامل دون أي مفتاح. لا تستخدم Base64 أبدًا "لحماية" كلمات المرور أو الرموز أو البيانات الحساسة. للحفاظ على السرية استخدم تشفيرًا حقيقيًا (AES-256-GCM)، وللمصادقة استخدم HMAC أو التوقيعات الرقمية.

مرجع سريع: Base64 في لغات البرمجة الشائعة

// JavaScript (browser & Node.js)
const encoded = btoa('hello world');       // "aGVsbG8gd29ybGQ="
const decoded = atob('aGVsbG8gd29ybGQ=');  // "hello world"

// Python
import base64
encoded = base64.b64encode(b'hello world').decode()
decoded = base64.b64decode('aGVsbG8gd29ybGQ=').decode()

// Go
import "encoding/base64"
encoded := base64.StdEncoding.EncodeToString([]byte("hello world"))

// Terminal
echo -n 'hello world' | base64
echo 'aGVsbG8gd29ybGQ=' | base64 --decode

جرّب أداة ترميز Base64 وفك ترميزه

رمّز Base64 وفك ترميزه، بالشكل القياسي أو الآمن للروابط، مباشرة داخل متصفحك. لا تغادر أي بيانات جهازك.
